# Bundled fonts

All fonts are served locally and need no runtime request to a font service. Each family is distributed under the SIL Open Font License, Version 1.1; keep its license file next to the font files.

## Lab type set

These are the only fonts the lab uses. The woff2 subsets were downloaded from Google Fonts (`fonts.gstatic.com`, via the CSS2 API) on 2026-10-01. The license texts come from the official Google Fonts repository.
